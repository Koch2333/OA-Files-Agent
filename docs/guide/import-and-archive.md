# 导入与归档

## 流程

| 步骤 | 页面 | 做什么 |
|---|---|---|
| 1. 导入 | 智能归档 / 工作台 | 把文件或整个文件夹拖进虚线框，或点“选择文件 / 选择文件夹”，再点“开始智能归档” |
| 2. 识别 | 任务详情 | 查看进度与结果（部门、类型、日期及证据）；不确定的字段显示“待审核” |
| 3. 计划 | 归档计划与审批 | 逐项核对“原名 → 新名”“原路径 → 目标路径”，需要时点“修订”改部门 / 类型 / 日期 / 名称 |
| 4. 批准 | 同上 | 点“批准计划”。批准前不会动任何文件 |
| 5. 执行 | 同上 | 点“执行归档”（与批准是两个独立步骤） |
| 6. 台账 | 台账 | 自动记录；搜索、筛选、排序，“导出 Excel” |

支持读取内容的格式：Word（`.docx` `.doc` `.odt` `.rtf`）、Excel（`.xlsx` `.xls` `.ods` `.csv` `.tsv`）、PowerPoint（`.pptx` `.ppt` `.odp`）、`.pdf`、图片（`.png` `.jpg/.jpeg` `.jfif` `.bmp` `.tif/.tiff` `.webp` `.gif`）、文本/网页（`.txt` `.md` `.html`）、邮件（`.eml` `.msg`）；旧版 Office 无需转换。系统按内容而不是扩展名识别格式（例如网页另存成 `.xls` 也能读）。**任何其他格式、加密/损坏或空的文件同样会被接收**：它们读不了内容，只依据文件名判断，界面标注“仅依据文件名”，一定留给人工确认，全自动模式也不会自动归档它们；原件不会被修改。不支持压缩包，请先解压。完整说明见用户手册第 2.1–2.3 节。

## 导入没有大小和数量上限

早期的“每批 100 个、单文件 20 MiB、整批 128 MiB”限制已经取消。

| 方式 | 适用 | 特点 |
|---|---|---|
| 可续传分片上传 | 浏览器（企业版与桌面版） | 每个文件拆成 8 MiB 分片；失败自动退避重试；刷新页面或断网后从服务器已收到的位置继续；3 个文件并行；显示进度、速度、剩余时间 |
| 本机路径导入 | 仅 Windows 桌面版（`local` 模式） | “从本机选择文件 / 文件夹（免上传）”：后端直接按路径流式复制到暂存区，源文件只读 |
| 一次性 multipart | 脚本、小批量 | `POST /v1/imports`，无上限，边收边写盘 |

界面自动选择：不超过 100 个文件且总计不超过 32 MiB 时用一次 multipart，否则用分片上传。

保护措施：

- **磁盘空间检查始终开启**：不足时返回 HTTP 507（“磁盘空间不足：需要 X，剩余 Y”），始终保留约 512 MiB（`OA_DISK_RESERVE_BYTES`）。请按“待导入文件总大小 + 归档副本”规划磁盘，因为原件先进暂存区，归档时再复制一份。
- 可选的管理员安全阀（默认关闭）：`OA_MAX_UPLOAD_BYTES`、`OA_MAX_BATCH_FILES`。
- 只有连接停滞（2 分钟收不到任何字节）才会断开，慢但持续的上传不会被超时打断。
- 反向代理必须取消请求体大小限制并关闭请求缓冲，见[大文件与批量导入](/大文件与批量导入)。

### 超大文件如何识别

文件无论多大都会被完整接收、计算 SHA-256、保留原件。识别阶段有保护：

- 超过 256 MiB（`OA_EXTRACT_MAX_BYTES`，0 = 不设保护）的文件不做全文提取 / OCR，只按文件名与元数据判断，标记为“**待人工审核**（元数据判断）”。你可以在审核页手动指定部门 / 类型 / 日期后正常归档。
- 即使在保护线内，也只读取有限内容：PDF 最多前 300 页，OCR 最多前 50 页，Excel 最多前 5000 行，单次解析有超时。识别依据来自文档开头部分，这是设计取舍。
- 超过保护线的文件无法在线预览。

## 手动修订与纠错

- 计划页每项都有“修订”。部门、类型是可输入的下拉框：候选值自动生成（内置词表 → 台账中已用过的值 → 本任务计划中的值，不区分大小写去重，保留值「其他」固定在最后），也可以直接输入新值，校验规则与后端一致（不含 `\ / : * ? " < > |`，≤ 60 字符）。
- **「其他」分类**：部门/类型无法识别时，计划层确定性地暂填「其他」（路径与新名因此可预览，如 `其他/2026/…`），并标记为系统占位（计划条目的 `fallback_fields`）。这不是模型的判断：分析结果与证据仍为空，该项保持“待人工确认”，不能批准，全自动模式下也留在计划里等人处理。逐项“确认「其他」”或“确认全部暂填的「其他」”后才能批准；改成真实的部门/类型同样视为确认。
- 台账读出时，空值/未知值显示并筛选为「其他」，导出的 Excel 同样如此（不改写存量数据）。
- 步骤提示：工具栏的 ① 批准计划 → ② 执行归档 用箭头连接，② 在批准前是锁定的（点击会说明原因和下一步）；批准后提示“下一步：点击「执行归档」”，不会自动执行。
- 文件详情的“纠错”：用一句话说明正确的部门 / 类型 / 日期，系统先给出“修改前 → 修改后”对比，确认后才应用，只影响该文件。
- 归档命名与目录由规则决定：占位符 `{date}{year}{month}{day}{department}{type}{original}{stem}{ext}`，例如 `{department}/{year}/{type}`；企业模板（关键词、部门与文种对应、日期来源与优先级）在“模板与规则”页配置。

## 执行的安全保证

- 原件只复制不移动，不覆盖已有文件；重名自动加序号。
- 执行带 `Idempotency-Key`，有日志（journal），可恢复、可回滚。
- 所有写入都在 `internal/archive`；模型没有写权限。

## 回滚（撤销）

计划页“撤销本次归档”（全自动任务卡片上是“撤销本次全自动归档”）会移除本次发布的文件副本，并同步移除台账记录，条目回到待审核计划；导入时保存的原件不受影响。

限制：只在文件**内容未被改动**时才会删除；已被改名 / 移动 / 删除的文件不能再整体撤销，请在文件管理里单独处理。撤销越早越好。

## 重试

- 识别失败（含大模型 HTTP 错误）：在任务页点重试，只重新识别失败的文件，已成功的结果不变；重复点击幂等。
- 大模型的 429 / 5xx / 网络错误本身会先自动退避重试，见[配置大模型密钥](./llm-keys#失败与重试)。
- 存储连接的同步备份失败：在“同步记录”里手动重试。

## 全自动模式

“全自动”让大模型直接决定并归档，不经人工审批，**可能出错**。启用时必须原文阅读风险提示、勾选确认并等待 3 秒；确认只在当前页面会话内有效。模型不确定的文件不会自动归档，而是留在计划里等你审核。自动归档的台账记录带“全自动 · 模型名”标记，可用“仅全自动”筛选，Excel 导出带“决策方式”列。建议先用人工审核跑一批，确认效果后再使用；涉密文件请不要使用大模型。管理员可在 AI 使用策略里关闭全自动。

## 文件管理

“文件管理”页浏览归档目录：预览（PDF / 图片按页，Word 与 Excel 解析后安全渲染）、新建文件夹、重命名 / 移动（不覆盖，同步台账）、删除到可恢复的回收站。支持多选与批量下载 / 校验 / 移动 / 删除：文件夹或多选下载自动打包为流式 ZIP（含 `MANIFEST.sha256`）；任务相关文件带 SHA-256，列表懒加载、按需重新校验；移动 / 还原按内容哈希判定重复与冲突（`on_conflict`：ask 默认不改动并返回冲突清单，skip / rename / replace），替换时旧文件先进回收站。接口见 `POST /v1/fs/download`、`/v1/fs/verify`、`/v1/fs/bulk/move`、`/v1/fs/bulk/trash`。Windows 本机可“在资源管理器中显示”（仅回环请求，`OA_ALLOW_REVEAL=0` 可关闭）。

## 存储连接（可选，管理员）

可作为导入来源，也可作为归档副本的只增备份目的地（S3 兼容、Azure Blob、WebDAV、SFTP、FTP、SMB、钉钉钉盘等）。凭据加密保存，不覆盖、不删除远端原文件；同步备份意味着归档文件会离开本机。`OA_STORAGE=off` 关闭该功能。网盘类对接仅用模拟服务测试过，首次使用请先“测试连接”。见[用户手册 §6.5](/用户手册)与[存储连接设计](/storage-design)。
