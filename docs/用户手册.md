# OA 文件智能归档 · 用户手册

## 1. 启动与停止
1. 解压整个文件夹到本机任意目录（路径建议不含特殊符号）。
2. 双击 **`start.bat`**。首次启动需初始化内置数据库，约 30 秒；完成后浏览器自动打开 `http://127.0.0.1:8080`。
3. 使用结束后**关闭黑色命令窗口**即可停止全部服务。数据保存在 `data\` 目录，下次启动继续使用。

无需安装 Python、数据库或 Office；程序内置文档解析（Word/Excel/PPT 含旧版、PDF、文本/网页/邮件）与 OCR（图片、扫描件）。

## 2. 基本流程（4 步）
1. **智能归档**页：把文件或**整个文件夹**拖进虚线框（也可点“选择文件/选择文件夹”）。支持 Word / Excel / PPT（含旧版 `.doc` `.xls` `.ppt`，无需转换）、PDF、图片、文本、网页、邮件等（完整清单见 2.1）；其他格式以及加密/损坏/空文件也会接收，只依据文件名判断并标上“仅依据文件名”，需要你确认。点“开始智能归档”。
2. **任务详情**页：查看进度与识别结果（所属部门、文件类型、生成日期及证据）。识别不确定的字段显示“待审核”，系统不会凭空填写。
3. **归档计划与审批**：逐项核对“原名→新名”“原路径→目标路径”。点“修订”可手动改部门/类型/日期/名称。先点**批准计划**，再点**执行归档**（两步分开，批准前不会动任何文件）。工具栏上两个按钮标了①②并用箭头连起来：①未完成时②是锁定的，点击锁定的按钮会提示“请先批准计划，再执行归档”和下一步动作；批准成功后会提示“下一步：点击「执行归档」”（不会自动执行）。首次打开待批准计划时还有一次性的步骤提示，点“知道了”后不再出现。
   - **部门/类型下拉**：修订对话框里的“所属部门”“文件类型”是可输入的下拉框，候选值自动生成（内置词表、台账里已用过的值——用得多的在前、本任务计划里出现的值），输入即过滤；候选里没有的值直接输入即可（列表底部会出现“新建值”），之后它会自动出现在候选里。键盘：↑↓ 选择、Enter 确认、Esc 关闭、Alt+↓ 展开。不能含 `\ / : * ? " < > |`，最长 60 个字符，不合规时输入框下方直接提示。
   - **「其他」分类**：部门或类型无法识别时，计划**自动暂填「其他」**（目标路径、新文件名因此已可预览，如 `其他/2026/…`），但这是系统占位，不是 AI 的判断：该项会显示“其他 · 待确认”，仍属于“待人工确认”，**不能批准**，全自动模式下也不会自动归档。逐项点“确认「其他」”（或点“修订”后保存）即视为确认；也可以一次点“确认全部暂填的「其他」”（会显示数量并二次确认）。当然也可以在下拉框里改成真实的部门/类型。修订时把部门/类型留空保存，会询问是否归入「其他」。日期仍需另行确认。原件只复制不移动，也不会覆盖已有文件；重名会自动加序号。
4. **台账（目录日志）**：自动记录每次归档；支持关键词搜索、筛选、排序，点“导出 Excel”下载 `.xlsx`。台账里部门/类型为空或未知的记录一律显示为「其他」（旧记录也一样，只是显示，不改写数据）；部门/类型筛选里选「其他」会同时匹配显式的「其他」与空值，导出的 Excel 里也不会出现空白的部门/类型。

归档后发现问题：计划页“撤销本次归档”只会移除本次发布的文件副本（内容未被改动时），并同步移除台账记录。


### 2.1 支持的文件格式

下表是**能读取内容**的格式（来源：`contracts/formats.json`，后端、Worker、前端共用同一份清单）。**任何格式的文件都会被接收**（见下一节“读不了内容的文件”），不会因为格式不识别而导入失败。

| 类别 | 扩展名 | 说明 |
|---|---|---|
| Word / 文字 | `.docx` `.doc` `.odt` `.rtf` `.wps` | `.doc`（Word 97-2003）无需转换，直接读取正文、表格、页眉页脚、脚注、文本框；`.wps` 仅在内容是 Office 兼容格式时可读 |
| Excel / 表格 | `.xlsx` `.xls` `.ods` `.csv` `.tsv` `.et` | `.xls`（Excel 97-2003）读取各工作表的单元格（公式取缓存值、日期、隐藏表有标记）；CSV/TSV 自动识别 UTF-8、UTF-16、GBK/GB18030 编码；`.et` 同 `.wps` |
| PowerPoint / 演示 | `.pptx` `.ppt` `.odp` `.dps` | `.ppt`（97-2003）读取每页文字与演讲者备注；`.dps` 同 `.wps` |
| PDF | `.pdf` | 原生文字直接读取，扫描页自动 OCR |
| 图片 | `.png` `.jpg` `.jpeg` `.jfif` `.bmp` `.tif` `.tiff` `.webp` `.gif` | OCR 识别；多页 TIFF 每页识别；GIF/WebP 只取第一帧 |
| 文本 / 网页 | `.txt` `.md` `.html` `.htm` | 网页只取可见文字（脚本、样式忽略，不会联网） |
| 邮件 | `.eml` `.msg` | 主题、收发件人、正文、附件名（附件内容不读取） |

- **按内容识别，不只看扩展名**：Word/OA 系统常把网页、RTF、`.docx` 另存成 `.doc`，或把 HTML 表格存成 `.xls`。系统会按真实内容选择读取方式，并标记“扩展名与内容不符”；不会盲目信任扩展名。
- **不支持压缩包**（`.zip` `.rar` `.7z`）：不会解压，按“读不了内容的文件”处理。需要请先解压后再导入。
- **安全**：读取过程不会运行宏、不会联网、不会执行嵌入对象；有大小、行数、页数、解压倍数等上限，超限的文件只读取前面部分或按“读不了内容”处理。原件永远不会被修改。
- **真实性说明**：旧版 `.doc` / `.ppt` 由本项目自带的解析器读取（`.xls` 使用 xlrd）。开发中用真实的 Microsoft Office 16 保存了测试样本进行验证，但不同来源、不同版本的老文件仍可能有未覆盖的情况——遇到只读出部分内容的文件，会标记为“部分内容”。

### 2.2 读不了内容的文件（仅依据文件名）
加密/带密码、损坏、格式不识别、空文件、超过解析大小上限（`OA_EXTRACT_MAX_BYTES`）、解析超时、扫描件 OCR 没识别出文字——这些文件**不会变成“失败项”**：
- 系统只用**文件名**（以及你配置的模板里的文件名关键词）判断部门、类型和日期，界面显示“**仅依据文件名**”标记，说明形如“内容无法读取（已加密），仅依据文件名判断”。
- 文件名里没有依据的字段保持“待审核”，计划里按“其他”占位；**不会**拿文件修改时间当作文档日期，也不会编造内容。
- 这类条目一定是“待人工确认”：全自动模式也**不会**自动归档它们；你确认或修订后才能批准。
- 任务页会汇总“N 个文件无法读取内容，已按文件名处理”。原件不会被修改，归档名保持原扩展名。
- 只有连文件系统层面都读不了（例如无权限、复制中途出错）的文件才会显示为失败，并给出原因。

### 2.3 状态术语
- **已加密 / encrypted**：文件设置了打开密码，无法读取内容。
- **部分内容 / partial**：读到了一部分——内容超过上限被截断、文件部分损坏已尽力恢复、或文本编码是推测的（可能乱码）。已读到的文字仍用于识别。
- **扩展名与内容不符**：例如网页另存为 `.xls`，已按真实格式读取。

## 3. 企业自定义 OA 模板与归档规则
“模板与规则”页：
- **OA 模板**：设置文件名/正文关键词、部门与文种对应关系、日期来源与优先级；可停用、编辑、用样本文件“测试”。导入时可指定模板，也可自动按优先级匹配。
- **命名与归档规则**：用占位符 `{date}{year}{month}{day}{department}{type}{original}{stem}{ext}` 定义文件名与目录，如 `{department}/{year}/{type}`。

## 4. 文件管理
“文件管理”页浏览归档目录：
- **浏览与预览**：点文件夹进入；pdf/png/jpg 可直接预览，其余文件下载。台账管理的文件会显示部门·类型·日期。
- **预览**：点文件名即可在页面内预览——PDF、图片按页显示（翻页、缩放，多页 TIFF 可翻页），Word / PPT / 文本 / 网页 / 邮件显示文字、标题、表格，Excel / CSV 按工作表显示（行数很多时只显示前若干行并提示）。旧版 .doc/.xls/.ppt 同样可预览（版式与图片不显示，只显示文字内容）。导入的原件、归档计划中的每一项、归档后的文件都可预览；格式不识别的文件显示“暂不支持预览”，可下载查看。预览只读，不会改动文件。
- **整理**：新建文件夹、重命名、移动到其他文件夹。**不会覆盖**已有文件（目标已存在会提示）；改动会同步更新台账中的路径和规范文件名。
- **删除**：先进入“回收站”，可随时还原；删除期间台账记录标记为“已移除”。还原时原位置被占用，会按下面的冲突规则处理。
- **多选**：每行有复选框，表头复选框全选当前文件夹；Shift+点击选一段，Ctrl/⌘+点击增减，空格切换当前行，Ctrl/⌘+A 全选，Esc 取消。筛选、排序不会丢失选择，进入其他文件夹会清空。选中后底部出现操作条：**下载 · 校验 · 移动 · 删除到回收站 · 取消选择**。批量移动/删除一次完成，结果逐项列出（部分失败不影响其余项）。
- **下载**：单个文件原样下载；**文件夹或多选会自动打包成 ZIP**（服务器边读边打包，不占临时空间，没有大小上限；文件夹下载名为“文件夹名.zip”，多选为 oa-files-时间.zip）。ZIP 末尾附 `MANIFEST.sha256`，解压后在该目录运行 `sha256sum -c MANIFEST.sha256` 即可校验每个文件；与台账哈希不一致的任务文件另记在 `MANIFEST-NOTES.txt`。符号链接与内部隐藏目录不会被打包。演示模式下无法下载。
- **哈希与校验**：台账中的文件（任务相关文件）在归档时已计算 SHA-256。列表里显示：“未校验”（台账已记录，尚未重新计算）、“已校验”、“与台账不一致”（文件在系统外被修改过）、“非任务文件”。列表不会现场计算哈希；选中后点“校验”或在哈希详情中点“重新校验”才会读取磁盘重新计算（可复制哈希）。移动任务文件时会先校验，发现不一致会在结果里标出并写入审计，但不会改动文件，也不改写台账里的原始哈希。
- **冲突规则（以内容哈希为准，永不静默覆盖）**：同名且内容相同 = **重复**，不会再放入第二份（源文件保留）；同名但内容不同 = **冲突**；名称不同但目标文件夹（还原时为整个归档）里已有相同内容 = **相同内容警告**；文件与文件夹同名 = 类型冲突，永不互相替换。有冲突时系统先不做任何改动，弹出冲突对话框，逐项（或“全部应用”）选择：**跳过**、**保留两者**（新项加 ` (2)`、` (3)`）、**替换（旧文件进回收站）**——旧文件进入回收站可还原，不会被删除。移入已存在的同名文件夹时按项合并。名称比较忽略 Unicode 组合差异，在 Windows/macOS 上还忽略大小写。
- **在资源管理器中显示**（Windows 本机）：打开文件所在文件夹并选中它，或打开当前文件夹。只有在运行本程序的这台电脑上使用时可用；不想要这个按钮，可在 `oa-agent.env` 设置 `OA_ALLOW_REVEAL=0`。
- 已被改名/移动/删除的文件不能再用“撤销本次归档”整体撤销，请在文件管理中单独处理。

## 5. 识别引擎与大模型（可选）
左侧“设置与管理”→“设置”页的“识别引擎”：
- **离线规则**（默认）：不联网、不需要密钥，按文件名和正文关键词识别；证据不足的字段会标“待审核”。
- **大模型**：选择预设（默认 **DeepSeek**，其次 **通义千问**，另有 OpenAI、本机 Ollama、自定义），**Base URL 和模型名都可以自由修改**（任何提供 `/chat/completions` 的 OpenAI 兼容服务都行）。点“获取模型列表”可从服务商读取可用模型，也可手填；“测试连接”会检查密钥、模型和是否支持工具调用；“保存并生效”后立即使用，无需重启。
- **第一次拿 API Key（新手向导）**：在“设置 → 识别引擎”里选一个服务商。
  - **OpenRouter**：点“登录 OpenRouter，自动完成设置”，登录并点“授权”，之后全部自动（桌面版里登录页就在应用自带的窗口里打开，完成后窗口自己关闭）。
  - **DeepSeek / 通义千问 / OpenAI**：这些服务商没有“一键授权”，密钥必须你自己在它的网站上创建并复制一次。桌面版点“打开向导窗口，一步步带你拿到 Key”：左边是服务商的真实页面，右边是分步指引（登录 → 进入 API keys 页面 → 创建密钥，名称建议填 OA Agent → 复制，密钥通常只显示一次）。你只需要登录和点按钮；复制之后窗口会提示“识别到一把密钥，尾号 ••••abcd”，点“使用这个密钥”就会自动填入设置、测试连接并选好模型，最后点“保存并启用”。网页版点“打开密钥页面并显示指引”：服务商页面在新标签页打开，指引显示在设置表单旁边，复制后回到本页按提示粘贴。已经有 Key 的话直接点“我已经有 Key：直接粘贴”。
  - **管理已有密钥**（桌面版）：已连接后点“管理密钥”，窗口里能看到服务商、密钥名称、尾号和上次测试结果，可以“重新测试”“更换密钥”“换一个服务商”或“删除密钥”（删除前会再确认一次）。
  - **隐私**：向导窗口不会读取网页内容、账号或密码，也不会替你点击；只在你复制之后检查剪贴板里是不是一把密钥，并且要你点“使用这个密钥”才会用，用完会清空剪贴板里的这把密钥。窗口里的登录状态按服务商分别保存，想清除点“退出登录并清除本窗口数据”。登录需要的网站（例如 Google 单点登录）如果被拦截，面板会说明，可以改用邮箱登录或点“改用系统浏览器”。
- **OCR 质量差时的“抢救”技能**：扫描件、拍照件识别不佳（歪斜、倒置、光线差、字太小）时，系统会先评估 OCR 质量（置信度、乱码比例、关键字段是否找得到），再自动用增强、旋转、纠偏、高清渲染、二值化等模式重试并选取最好的结果；识别结果仍不可靠时一律标“待审核”，文件详情会显示 OCR 质量与所用模式。离线规则和大模型两种方式都会这样做。
- **视觉识别（可选，默认关闭）**：在“高级”里开启并填写支持图片输入的视觉模型后，OCR 质量仍差时可把页面图片交给该模型转写。**页面图片会发送给模型服务商**，涉密文件请勿开启。
- **密钥安全**：API Key 加密保存在本机，页面永远不显示已保存的密钥；更换服务商（Base URL）后必须重新输入对应密钥，不会把旧服务商的密钥发给新服务商。公网地址必须用 https（本机/内网才允许 http）。
- **隐私**：使用大模型时，文档中的文字会发送给所选服务商。涉密文件请用“离线规则”或本机模型（如 Ollama）。

## 6. 纠错（可选）
在文件详情点“纠错”，用一句话说明正确的部门/类型/日期。系统先给出“修改前→修改后”对比，确认后才应用；只影响该文件，不改全局规则。

## 6.5 存储连接（可选）
左侧“设置与管理”→“存储连接”页可添加（仅管理员）云存储或企业内部存储，用作**导入来源**，也可作为**归档副本的备份目的地**。不添加则完全不联网，整个功能可用 `OA_STORAGE=off` 关闭。

- 支持类型（共 16 种）：S3 兼容（AWS、阿里 OSS、腾讯 COS、华为 OBS、MinIO、R2 等）、Azure Blob、WebDAV、SFTP、FTP/FTPS、SMB；网盘：OneDrive/SharePoint、Google Drive、Dropbox、阿里云盘、百度网盘、123云盘；私有云：OpenList/AList、Seafile、Cloudreve；钉钉钉盘（企业内部应用）。网盘类需要自行在对应开放平台申请应用并填入 client id/secret 与 refresh token；refresh token 轮换后系统会自动加密回存。以上新增网盘/私有云均仅用模拟服务测试过，首次使用请先“测试连接”。
- 添加后先点“测试连接”：依次检查连接、读取目录，可选再做一次写入探测（探测文件随即删除）。SFTP 首次连接会显示主机指纹，需你确认后才信任。
- 导入：在“导入”页选“从存储连接导入”，选择远端文件或文件夹，之后与本机上传完全一样走识别→审核→归档。远端原文件不会被修改或删除。与上传一样没有文件大小和数量上限；格式不支持或空文件会作为失败项计入，不会让整批失败。
- 同步备份：连接可设为“手动”或“自动”。只增不改：目标已存在同名文件时改用带序号的名称，绝不覆盖；上传前后校验大小与哈希，失败自动退避重试，也可在“同步记录”中手动重试。删除连接不会删除远端文件。
- 隐私与安全：凭据加密保存（AES-GCM），界面和日志不回显；更换服务器地址必须重新输入凭据；云元数据等链路本地地址被拒绝；使用同步备份意味着归档文件会离开本机，请确认符合公司规定。
- 钉钉钉盘说明：仅支持企业内部应用（需 AppKey/AppSecret、操作人 unionId、存储读写权限）；个人版网盘无开放 API。该对接目前仅用模拟服务测试过，首次使用请先用测试连接验证。OpenList 的钉钉驱动只覆盖“钉钉文档”，不是钉盘。

## 6.8 登录与账号
**首次安装（企业模式）**：打开页面会自动进入“首次安装向导”，共 7 步：环境检查 → 初始化令牌 → 运行模式 → 创建管理员 → 域名与安全策略 → 绑定第一个多因素认证 → 完成。
- 初始化令牌只在服务日志和命令行出现一次（Docker：`docker compose logs api | grep SETUP`；服务器上：`oa-admin setup-token`）。从服务器本机访问时可跳过。
- 运行模式：**企业**（必须登录，推荐服务器使用）或**本机**（单机免登录，只有从服务器本机访问时才可选；任何能打开页面的人都是管理员，之后只能升级为企业模式，不能改回）。
- “RP ID”是 Passkey 绑定的域名（不含协议与端口），“允许的来源”是精确的访问地址。**之后修改域名会使已注册的 Passkey 全部失效。** 非 HTTPS 且非 localhost 的地址不能使用 Passkey，向导会说明原因，此时可只用验证器 App。
- 绑定第一个 MFA 后会显示 **10 个一次性恢复码，只显示这一次**：请复制或下载保存，并勾选“我已安全保存”后才能继续。初始化完成后向导不再出现。

**登录**：
- 用户名 + 密码；若账号绑定了多因素认证，再输入验证器 App 的 6 位验证码（输满自动提交），或使用 Passkey、恢复码。
- **Passkey 登录**：点“使用 Passkey 登录”，无需输入用户名，按系统提示用指纹、面容、PIN 或安全密钥验证即可。
- 连续输错密码会被临时锁定（管理员可解锁）；操作过于频繁时页面会提示等待的秒数。登录过期后会回到登录页，登录后返回原来的页面。

**账号安全**（右下角用户菜单 → 账号安全）：修改密码；绑定/关闭验证器 App（扫描二维码，或手动输入密钥）；添加、重命名、删除 Passkey（建议至少两个）；重新生成恢复码（旧码立即作废，新码只显示一次）；查看并退出自己的其他登录设备。删除登录方式、生成恢复码等敏感操作需要“近期认证”：会弹出对话框让你再输入一次密码或使用 Passkey。若策略要求多因素认证，未绑定时登录后只能先进入此页完成绑定。

**角色**：管理员（全部权限）；操作员（导入、审批、执行、纠错、文件管理、模板与规则；看不到设置、存储连接与管理页）；只读（只能查看任务、文件、台账、预览与导出，页面上不显示任何写入按钮）。

**管理员日常**（左侧“管理”分组）：
- **用户管理**：新建用户（选择角色，凭据为“临时密码”或“Passkey 邀请链接”）。临时密码和邀请链接**只显示一次**，请当场复制并通过安全渠道交给本人；用户首次用临时密码登录必须改密；邀请链接 24 小时内有效、一次使用。点用户可：改角色/显示名、停用/启用、重置密码、重置 MFA（用户丢失设备时）、解锁、吊销全部会话、生成邀请链接、删除。不能停用、删除或降级最后一个启用的管理员，也不能删除自己。
- **安全策略**：MFA 要求（不强制/管理员必须/所有人必须）、是否允许密码登录、空闲与最长会话时间、密码最短长度、锁定阈值与时长、Passkey 域名。改动域名需勾选“Passkey 将失效”确认。
- **会话管理**：查看所有登录会话，按用户筛选，强制退出。**审计日志**：登录、策略与用户变更等记录。
- 管理员自己丢失全部验证方式时，请在服务器上使用命令行 `oa-admin` 重置，而不是依赖网页。

## 6.9 AI 工作台与任务说明
左侧“AI 工作台”（操作员及以上可见）用来**给 AI 布置归档任务**。它不是聊天窗口：每次提交就是一个可追踪、可审计的任务。
- **写任务说明**：在“给 AI 的任务说明”里用一两句话写下要求（最多 2000 字），例如“只处理采购相关文件，按项目名归档”“把扫描件单独标记待审核”。下方的示例按钮可以一键填入。说明只用来指导分类与命名，**不能**让 AI 获得额外权限，也不会改变路径安全规则；文档里的文字永远只是数据，不会被当作指令。
- **选文件**：把文件或整个文件夹拖进来，或点“选择文件/选择文件夹”；管理员还可以点“从存储连接选取”。**文件大小和数量都不受限制**：大文件会自动分块上传，网络中断或刷新页面后再次提交会从断点继续，界面显示进度、速度和剩余时间；Windows 桌面版还可点“从本机选择文件/文件夹（免上传）”直接复制本机文件。格式不支持或空的文件会在列表里标出，仍会提交并显示为失败项，不会让整批失败。超大文件只做文件名/元数据判断并标记为“待人工审核”，详见《大文件与批量导入》。
- **处理模式**：默认“人工审核（推荐）”——大模型给出归档计划，由你逐项核对、批准、执行。“全自动”见下一节。
- **没有大模型时**：页面顶部会出现醒目的提示卡，整个输入区被禁用。管理员点“去配置全局大模型”；操作员若管理员开放了个人 API，可点“配置我的个人大模型”，否则请联系管理员。已配置时顶部显示“将使用：全局/个人 · 模型名”。
- **最近任务**：右侧按时间倒序列出任务，显示说明、模式（人工审核/全自动）、所用模型与来源（全局/个人）、状态与进度；点“Agent 轨迹”可看实时处理过程，并可跳到归档计划与台账。
- “智能归档”页也有同样的“人工审核 | 全自动”切换和可折叠的“给 AI 的说明”（需要已配置大模型）。

## 6.10 全自动模式：风险与撤销
“全自动”让大模型**直接决定并归档文件，不经过人工审批**。它比人工审核快，但**可能出错**：错误的部门、类型、日期或文件名会直接进入归档目录。
- **启用方式**：选择“全自动”时会弹出警告框，必须**原文阅读**风险提示、勾选“我已阅读并理解上述风险，由此产生的后果由我/本组织承担”，并等待 3 秒后才能点“确认启用”。按 Esc 或点取消会回到“人工审核”。这次确认只在**当前页面会话**内有效，刷新页面或重新打开后会再次询问。
- **什么时候不能选**：管理员关闭了“全自动归档”、尚未配置大模型、或你是只读账号。选项会变灰并说明原因。
- **结果**：任务页会一直显示“本任务为全自动模式：由模型 xxx 决定，无人工审批”。模型不确定的文件**不会**被自动归档，而是留在计划里等你审核；AI 工作台的任务卡片会显示“已归档 N、留待人工审核 M”。
- **台账标记**：自动归档的每一条台账记录都标记“全自动 · 模型名”，台账页可用“仅全自动”筛选；导出的 Excel 也带“决策方式”列。人工批准的记录显示“人工审核”。
- **撤销**：任务卡片上的“撤销本次全自动归档”（或计划页的“撤销本次归档”）会移除本次发布的文件副本（仅当文件内容未被改动时），台账记录同步移除，条目回到待审核计划；导入时保存的原件不受影响。**越早撤销越好**——在撤销之前，被错误归档的文件可能已被同事看到或引用。
- 建议：先用人工审核跑一批，确认说明与模型效果后再对同类文件使用全自动；涉密文件请不要使用大模型。

## 6.11 全局大模型与个人大模型
“设置 → 大模型”有两张卡片：
- **全局大模型（全员共用）**（仅管理员）：这是默认配置，员工的任务都用它，除非员工设置了自己的个人大模型。配置方法同第 5 节（预设、Base URL、模型、API Key、测试连接、保存并生效）。
- **我的个人大模型**（操作员及以上，仅在管理员允许时出现）：只对**你本人**提交的任务生效，并且**优先于**全局配置。密钥加密保存在服务器，页面只显示尾号。个人配置的**地址规则比全局更严格**：默认只允许公网 https 地址，不能填写内网或本机地址（管理员可在策略里放开）；测试连接有次数限制，过于频繁会提示等待。点“删除个人配置，改用全局”可随时回到全局配置。
- 页面上方的状态行会告诉你：你的任务现在会使用哪个配置。从 AI 工作台点“去配置”会直接定位到本区域（`/settings#llm`）。
- 首次安装向导在绑定 MFA 之后新增了“配置全局大模型（推荐）”一步：可以直接填写并测试，也可以跳过（“稍后在 设置 中配置；未配置时 AI 工作台不可用”），并可顺便决定是否允许员工配置个人 API。本机单用户模式的向导没有这一步，完成后到设置里配置即可。

## 6.12 管理员策略（AI 使用策略）
“设置”页最下方的“AI 使用策略”（仅管理员），三个开关即时生效并记入审计日志：
- **允许员工配置个人大模型 API**（默认关）：关闭后所有人只能用全局大模型，已保存的个人配置不再生效。
- **允许个人 API 使用内网/本机地址（有安全风险，默认关闭）**：开启后员工可以让服务器去访问内网或本机的任意地址（服务端请求伪造风险）。只有确实需要（例如员工自建本地模型）时才开启。
- **开放“全自动归档”**（默认开）：关闭后所有人只能用人工审核。
管理员也可以在这里随时关闭全自动来应对事故；已经归档的内容可用“撤销”处理。

## 6.13 运行诊断与错误报告
管理员在“管理 → 运行诊断”可以看到：
- **系统状态**：版本与提交号、构建模式（调试版/发布版）、操作系统、已运行时间、数据库与文档 Worker 的状态（正常/异常）、归档目录磁盘剩余空间（低于 10% 或 10 GiB 时变红并提示）、是否独立运行。若“上次运行异常结束”（崩溃或被强制结束），页面顶部会出现醒目提示，点“查看相关报告”可直接看到对应记录。
- **错误报告**：同一个错误按指纹合并成一条，显示来源（接口/流水线/Worker/存储/浏览器/进程守护/启动/大模型）、级别（错误/Panic/致命）、错误码、消息、次数、首次与最近时间。可按来源、级别、未解决/已解决、关键词（消息/错误码/请求编号）筛选。点一行打开详情：已脱敏的调用栈（可复制）、上下文信息、最近 20 次发生的时间/请求编号/用户；可“标记已解决”“重新打开”或“删除”。没有记录时显示“没有错误报告”。
- 左侧“运行诊断”旁的红色数字是**未解决**的报告数，每分钟刷新一次。
- **下载诊断包**：生成一个 zip，包含版本与环境摘要、脱敏配置、最近日志、错误报告、迁移状态。**不包含**密钥、令牌、密码或任何文档内容。生成需要几秒，期间按钮会显示“正在生成”。

## 6.14 遇到问题怎么反馈
1. **页面上的红色错误提示都会带“请求编号”**，旁边有“复制错误信息”按钮。请把这段文字（含编号、时间、页面）发给管理员，管理员据此可在日志与“运行诊断”里精确定位。
2. 看到“服务器内部错误，已记录，请联系管理员并提供请求编号”：说明服务器出错且已自动记录，不需要重复操作，把编号发给管理员即可。
3. 页面某个区域崩溃时，只有该页面会显示“这个页面出了点问题”，可点“重试”，导航仍然可用；右下角会提示“页面出现了问题，已记录（编号 …）”，可点“复制详情”。相同的错误一分钟内只上报一次，上报内容不含你输入的表单内容、令牌或响应正文。
4. 提示“无法连接到后端服务”：说明后端没有运行或网络断开。独立版请确认程序仍在运行（必要时重新启动）；页面每 5 秒自动重试，恢复后提示自动消失。
5. 问题反复出现时，请管理员在“运行诊断”下载**诊断包**一并发给技术支持。

## 6.16 大模型出错了：自动重试与“重试”按钮

识别文件时如果大模型服务商返回 HTTP 错误或连不上，系统先**自动重试**（最多 3 次，间隔逐次加长并带随机抖动；服务商给出 Retry-After 时按它等待，超过 8 秒则不再干等，直接告诉你需要等多久）。仍失败的文件会明确标为“模型出错”，已识别成功的文件不受影响。

出错时在任务卡片、任务详情、归档计划页和顶部状态条都会出现红色提示，写明原因（如“服务商返回 429：请求太频繁或额度不足，已自动重试 3 次”）和 HTTP 状态码，并给出按钮：

- **重试**：只重新识别失败的文件，已成功的结果保留，计划会重新生成；重复点击不会重复排队。429 且服务商给了等待时间时，按钮显示倒计时。只读账号看不到按钮。
- **检查 API Key**：401/403/404 这类原因重试不会成功，主按钮改为跳到 设置 → 大模型；“重试”降为次要按钮，改完设置后仍可点。

| 状态 | 含义 | 建议 |
|---|---|---|
| 401 / 403 | API Key 无效、过期或没有权限 | 检查 API Key（不会自动重试） |
| 404 | 接口地址或模型名称不存在 | 检查 Base URL 与模型名（不会自动重试） |
| 400 / 422 | 服务商拒绝请求（常见于模型名不受支持） | 换一个模型 |
| 408 / 超时 | 服务商没有及时回应 | 已自动重试；可稍后点“重试” |
| 429 | 请求太频繁或额度用完 | 等倒计时结束再重试；反复出现请检查余额 |
| 5xx | 服务商暂时故障 | 已自动重试；通常稍后点“重试”即可 |
| 无法连接 | 网络、代理或 Base URL 有问题 | 检查网络后重试 |

错误信息不会包含 API Key、请求内容或文档文字。管理员可在 运行诊断 中查看对应的错误编号（PROVIDER_HTTP_xxx）。

## 7. 配置
编辑程序目录下的 `oa-agent.env`（文本文件，里面有说明）：归档目录、监听地址、是否接入大模型、是否显示“在资源管理器中显示”等。默认使用离线规则识别，不联网。

## 8. 常见问题
- **端口被占用**：在 `oa-agent.env` 设置 `OA_LISTEN_ADDR=127.0.0.1:8081`。
- **页面提示后端异常**：查看 `设置` 页“服务状态”，并查看 `data\logs\` 下日志。
- **把文件拖进窗口没有反应（Windows 桌面版）**：最常见原因是程序以“管理员身份”运行。Windows 的界面特权隔离（UIPI）会悄悄拦截从普通的资源管理器拖向管理员窗口的文件，页面根本收不到拖放事件。界面检测到这种情况时会在导入区显示提示。处理：完全退出程序，用普通方式重新打开（双击快捷方式，不要右键“以管理员身份运行”；如果 exe 属性 → 兼容性里勾选了“以管理员身份运行此程序”，请取消）。在此之前可用“选择文件 / 选择文件夹”按钮或粘贴（Ctrl+V）。另外，如果资源管理器本身是管理员权限也会同样被拦截。拖到页面其他位置也能接收文件（会出现“松开即可上传”遮罩），不会导致窗口跳转。
- **识别结果不准**：先在“模板与规则”页建立匹配模板；仍不准的在计划页手动修订。
- **数据位置**：`data\archive`（归档文件）、`data\spool`（导入时保存的原件副本）、`data\pg`（数据库）。备份时整体复制 `data\` 即可（先关闭程序）。
