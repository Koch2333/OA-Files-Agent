# 界面指南（工作台与导航）

## 1. 侧栏
- **常用**：工作台 · 智能归档（操作员+）· AI 工作台（操作员+）· 任务中心（角标 = 等你审批的任务数）· 文件库 · 台账（目录日志）· 文件管理。
- **设置与管理**（默认收起，进入其子页面自动展开，本次会话记住选择）：模板与规则、存储连接（管理员）、设置（操作员+：大模型/个人设置）、用户管理、安全策略、会话管理、审计日志、运行诊断（管理员，带错误角标）。
- 所有网址不变；详情页（任务、计划）仍高亮“任务中心”。窄屏侧栏收成图标栏，“设置与管理”图标可点开。

## 2. 工作台怎么用
1. 把文件或整个文件夹拖进顶部虚线框（也可点“选择文件/选择文件夹”，或直接粘贴文件）。
2. 出现确认条：N 个文件 · 总大小 · 将识别的格式。选择运行方式（人工审核，推荐 / 全自动，会弹出风险确认），已配置大模型时可写一句说明。
3. 点“开始智能归档”（不会自动提交）。随后在任务页看“Agent 执行进度”，轮到你时去审批。
- 下方：统计条（点击进入对应筛选列表）→ 左侧“待你处理”（待审批计划、需人工确认的文件、失败任务可重试）和“进行中的任务”（实时进度）→ 右侧“最近归档”（可导出 Excel；点一行看原文件名、完整路径、SHA-256、预览、识别证据）。
- 顶部搜索框直达台账关键词搜索。只读账号看到被禁用的拖入区和原因说明。

## 3. Agent 执行进度（5 步）
解析文件 → AI 识别 → 生成归档计划 → 人工审批 → 执行归档。
圆点含义：绿色勾 = 完成；转圈 = 进行中（显示已处理/总数）；黄色沙漏 = 等你操作（“等待你审批”“待执行”）；红色 = 出错；灰色禁止 = 已取消；虚线 + “全自动”= 全自动任务跳过审批。

## 4. 列表与密度
- 最近归档/台账“简洁”视图只显示易读文件名与部门、类型、日期标签；原文件名与完整路径在详情里。台账“完整列”保留全部列（默认）。
- 用户菜单可切换表格行高（舒适/紧凑）。
- 演示模式可加 `?mock_tasks=all` 查看每种任务状态的进度形态。
