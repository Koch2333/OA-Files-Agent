features:
  - title: 先预览，再审批，再执行
    details: 批准与执行是两个独立步骤。原件只复制不移动，不覆盖，重名自动加序号；每次归档有日志，可撤销。
  - title: 证据不足就留空
    details: 无法确认的字段保持为空并标记“待审核”，不会编造。文档里的文字只当数据，不当指令。
  - title: 不限大小的导入
    details: 分片可续传上传，网络中断或刷新后从断点继续；桌面版还可直接按本机路径复制。超大文件只按文件名判断并转人工审核。
  - title: 大模型可选，失败可重试
    details: 默认离线规则；也可接入 DeepSeek、通义千问、OpenAI、OpenRouter 或任何 OpenAI 兼容服务。429 与 5xx 自动退避重试，界面可一键重试。
  - title: 个人版与企业版
    details: Windows 桌面版单用户免登录；Linux Docker Compose 企业版支持多用户、MFA（TOTP / Passkey）、审计日志。
  - title: PostgreSQL / MySQL / SQL Server
    details: 默认 PostgreSQL（Windows 内置）；可复用已有 MySQL 8.0+ 或 SQL Server 2019+。跨库数据迁移暂未提供。
